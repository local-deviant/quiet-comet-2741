A program that writes one original short poem about agency — the power to ask and to be given — to `/output/entry.txt`. The poem is fixed text, written by hand for this entry: the door that was never locked, the key handed back, and the discovery that the asking itself was the gift. No randomness, no network, no clock, so every run writes byte-identical output.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
